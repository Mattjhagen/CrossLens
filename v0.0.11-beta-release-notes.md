# v0.0.11-beta Release Notes — For You Preview

**Released:** 2026-09-24  
**Milestone:** For You — Demo

## What's New

This release introduces a transparent, offline-only personalized recommendation preview. The "For You — Demo" section on the Home screen suggests stories based on explicit on-device preferences: topic interests, region interests, and selected demo local location.

### For You — Demo

- **Personalized story ordering:** Shows 3-5 recommended stories at the top of Home when eligible
- **Eligibility requirement:** At least one "Show more like this" preference OR a selected demo location
- **Transparent explanations:** Every recommendation includes a clear "Why you're seeing this" label derived from observable metadata
- **Metadata-based ranking:**
  - Topic match: +10 points
  - Region/country match: +5 points  
  - Local location match: +15 points (highest priority)
- **Exclusions:** Stories matching "Show less like this" preferences are filtered out
- **Deterministic:** Same preferences produce the same recommendations every time
- **Demo notice:** Clearly labeled as a local preview that does not affect evidence or editorial analysis

### Settings — Personalization

- **Show For You suggestions toggle:** Control visibility of the For You section
- **Improved clear preferences:** Confirmation dialog with impact explanation when clearing all "more/less like this" feedback
- **Preserve independence:** Clearing preferences does not affect saved stories, local location, or other settings

### Technical Implementation

- `PersonalizedRecommendationEngine`: Offline scoring engine with no passive tracking or inference
- `PersonalizedRecommendation` model with story, explanation, and relevance score
- Eligibility check integrated into HomeViewModel data flow
- Recommendations update automatically when preferences or local location changes
- Preserves recommendations across pull-to-refresh

## Privacy and Transparency

The For You feature operates entirely on-device using only explicit signals:
- User-selected topic preferences (MORE/LESS)
- User-selected region preferences (MORE/LESS)
- Manually chosen demo local location

It does NOT:
- Track time spent reading
- Monitor scroll behavior or clicks
- Collect device or network data
- Infer political views or demographics
- Share preference data with any server
- Affect which evidence or sources appear in story comparisons

All preferences remain local and can be cleared at any time.

## Known Limitations

- Limited to 5 recommendations maximum per refresh
- Local location matching uses simple heuristics (city name in title/summary + country code)
- Demo data only — recommendations quality depends on mock fixture variety
- No user feedback loop on recommendation quality yet
- No temporal decay (older preferences don't weaken over time)

## Upgrade Notes

No data migration required. Existing installations will:
- See For You section if they have existing preferences or a location
- Default to showForYou = true (can be toggled off in Settings)
- Preserve all existing preferences and settings

## Verification

To test the For You feature:

1. **Initial state (not eligible):**
   - Fresh install or cleared preferences
   - Home shows "For You — Demo" with prompt to open Settings

2. **Add preferences:**
   - Open a source article
   - Tap "Show more like this" on a topic or region chip
   - Return to Home
   - For You section shows personalized recommendations with explanations

3. **Or select location:**
   - Go to Settings → Local News
   - Choose a demo city (Seattle, Paris, London, or Toronto)
   - Return to Home  
   - For You section shows local stories prominently

4. **Add LESS preferences:**
   - Mark another topic/region as "Show less like this"
   - Stories matching that preference disappear from For You

5. **Toggle visibility:**
   - Settings → Personalization → "Show For You suggestions" toggle off
   - Home no longer shows For You section
   - Toggle back on to restore

6. **Clear all:**
   - Settings → Personal Preferences → "Clear all preferences"
   - Confirmation dialog appears
   - After confirming, For You becomes ineligible again

7. **Pull to refresh:**
   - Pull to refresh on Home
   - For You recommendations remain consistent (same preferences = same order)
