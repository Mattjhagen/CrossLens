## For Developers

### Debug Builds (No Changes)

Debug builds work exactly as before with no additional setup:

```bash
# Works without any signing configuration
./gradlew :app:assembleDebug
./gradlew :app:installDebug
```

### Release Builds (New Setup Required)

To build signed release APKs, you must first:

1. **Generate a signing key:**
   ```bash
   keytool -genkeypair \
     -keystore keystore/crosslens-release.jks \
     -alias crosslens-release-key \
     -keyalg RSA \
     -keysize 4096 \
     -validity 10000
   ```

2. **Create keystore.properties:**
   ```bash
   cp keystore.properties.example keystore.properties
   # Edit with your actual credentials
   ```

3. **Build release APK:**
   ```bash
   ./gradlew :app:assembleRelease
   ```

See [docs/RELEASE_SIGNING.md](docs/RELEASE_SIGNING.md) for detailed instructions.

## Security & Privacy

### What's Protected

✅ **Automatically gitignored:**
- `*.jks` (keystore files)
- `*.keystore` (alternative keystore extension)
- `keystore.properties` (signing credentials)
- `google-services.json` (Firebase config, for future use)

✅ **Provided as examples only:**
- `keystore.properties.example` (placeholders, safe to commit)

### User-Owned Keys

CrossLens uses a **user-owned signing key** model:
- You generate and control your own signing key
- You are responsible for secure backup
- Claude/Anthropic never has access to your key
- You can rotate keys using Google Play App Signing

## One-Time Setup Steps

After installing this release, you must:

1. **Read the signing guide:**
   ```bash
   cat docs/RELEASE_SIGNING.md
   ```

2. **Generate your signing key:**
   ```bash
   mkdir -p keystore
   keytool -genkeypair \
     -keystore keystore/crosslens-release.jks \
     -alias crosslens-release-key \
     -keyalg RSA \
     -keysize 4096 \
     -validity 10000
   # Choose strong passwords and store in password manager
   ```

3. **Record SHA-256 fingerprint:**
   ```bash
   keytool -list -v -keystore keystore/crosslens-release.jks | grep SHA256
   # Save this for Firebase setup
   ```

4. **Create keystore.properties:**
   ```bash
   cp keystore.properties.example keystore.properties
   # Edit with your actual values
   ```

5. **Back up your keystore securely:**
   - Copy to encrypted cloud storage (1Password, iCloud, Google Drive)
   - Store password in password manager
   - Test restore process

6. **Test release build:**
   ```bash
   ./gradlew :app:assembleRelease
   apksigner verify app/build/outputs/apk/release/app-release.apk
   ```
