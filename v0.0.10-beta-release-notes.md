# CrossLens v0.0.10-beta — Pull to Refresh

**Feature:** Polished pull-to-refresh for reloading offline demo data  
**Status:** Pre-release (development milestone, not production-ready)  
**Build:** Debug APK for Android 10+ devices

---

## What's New in v0.0.10-beta

### Pull to Refresh

**Reload demo data with a familiar gesture.** Pull down from the top of the Home feed to refresh the deterministic offline demo edition.

**Key characteristics:**
- **Native Material 3 gesture** — Smooth, polished pull-to-refresh using Jetpack Compose's PullToRefreshBox
- **Offline demo mode** — Reloads local Room fixtures without making network requests or implying live news was downloaded
- **Last refreshed timestamp** — Clear visibility of when demo data was last reloaded (e.g., "2 min ago", "Just now")
- **Demo data labeling** — "Demo data refreshed" messaging makes the mock behavior explicit
- **Preference preservation** — Location selection, local filter state, theme, and all user settings survive refresh
- **TalkBack accessible** — Screen reader announces "Pull to refresh demo data" and "Refreshing demo data" states
- **Reduced motion aware** — Refresh animation respects system accessibility settings
- **Works everywhere** — Functions correctly with local filter on/off, empty states, light/dark themes, large text, RTL, system back navigation, and offline airplane mode

### User-Visible Behavior

1. **Pull down** from the top of the story feed on the Home screen
2. **Loading indicator** appears while refresh is in progress
3. **Demo data reloads** from Room database (deterministic fixtures)
4. **Timestamp updates** to show "Last refreshed: Just now"
5. **All preferences preserved** — Your selected location, filter state, theme, and saved stories remain unchanged

**What refresh does NOT do:**
- Does not download new articles from the internet
- Does not make any network requests
- Does not claim to show "live" or "breaking" news
- Does not change your preferences or settings
- Does not add fake "new articles" badges or notifications

---

## Important Limitations

### Demo-Only Behavior

Pull-to-refresh **reloads the deterministic offline demo edition** from local Room fixtures. This milestone demonstrates the UX pattern for future live data updates.

**This is not live news ingestion:**
- No network requests are made during refresh
- No new articles are downloaded or created
- Demo data is identical after each refresh (deterministic fixtures)
- Timestamp shows when the user last triggered refresh, not when "news" was published

### Production Boundaries Not Crossed

- No live news APIs or ingestion services
- No Google Play Billing integration
- No analytics, crash reporting, or telemetry
- No signing or release distribution workflow

## How to Use Pull to Refresh

1. Open **CrossLens** and navigate to the **Home** feed
2. **Pull down** from the top of the story list
3. **Release** to trigger refresh
4. **Watch** the loading indicator while demo data reloads
5. **See** "Last refreshed: Just now" appear below the app subtitle

The timestamp will update automatically as time passes ("2 min ago", "1h ago", etc.).
