# v0.0.15-beta: Article Image Support

**Date:** 2026-09-24  
**Branch:** `feature/live-feed-v0.0.14-beta` → merged with image support  
**Status:** Implemented and installed on device

## Overview

Added automatic image extraction from RSS feeds with display on the home feed story cards. Images are sourced from standard RSS enclosure tags and Media RSS extensions when available.

## What Changed

### RSS Image Extraction

**RssParser.kt:**
- Added `imageUrl` parsing from multiple RSS formats:
  - `<enclosure type="image/*" url="...">` (RSS 2.0 standard)
  - `<media:thumbnail url="...">` (Media RSS)
  - `<media:content medium="image" url="...">` (Media RSS)
- HTTPS-only validation for image URLs
- Prioritizes first available image per article

**Example RSS sources with image support:**
- BBC News: Uses `<media:thumbnail>` extensively
- NY Times: Provides `<media:content>` with images
- The Guardian: Uses `<enclosure>` tags
- Most other sources: Vary between formats

### Data Model Updates

**Database Schema v8:**
- Added `imageUrl: String?` to `ArticleEntity`
- Added `imageUrl: String?` to `StoryEntity` (representative image)
- Destructive migration (requires fresh install)

**Domain Models:**
- Updated `SourceArticleRecord` to include `imageUrl`
- Updated `Article` domain model to include `imageUrl`
- Updated `Story` domain model to include `imageUrl`
- Updated mappers to pass imageUrl through all layers

**Repository:**
- `LiveStoryRepository` now populates story imageUrl from first article
- Image URLs flow from RSS → Parser → Adapter → Repository → Entity → Domain → UI

### UI Implementation

**HomeScreen.kt StoryCard:**
- Added Coil `AsyncImage` component at top of card
- 200dp height image with `ContentScale.Crop`
- Crossfade animation on load
- Only displays when `story.imageUrl != null`
- Graceful fallback to text-only card when no image

**Visual Design:**
- Images span full card width
- Positioned above headline and summary
- Maintains existing text layout below image
- No image placeholder shown when URL absent

## Technical Details

### Image Loading
- Uses Coil library (already in project)
- Automatic caching and memory management
- Crossfade transition for smooth loading
- Content scaling preserves aspect ratio

### Privacy & Safety
- HTTPS-only image URLs enforced
- Images sourced directly from publisher RSS feeds
- No third-party CDN or proxy
- Respects same privacy model as text content

### Performance Considerations
- Images loaded asynchronously (non-blocking)
- Coil handles memory and disk caching
- Network requests cached per HTTP headers
- No impact on feed load time (parallel loading)

## Known Limitations

1. **No fallback image**: Cards without images show text-only (by design)
2. **Fixed height**: All images displayed at 200dp height
3. **No aspect ratio preservation**: Uses crop scaling (may clip)
4. **No error handling UI**: Failed image loads show empty space
5. **Database migration**: Requires fresh install or app data clear
