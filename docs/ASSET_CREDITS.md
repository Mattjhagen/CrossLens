## CrossLens App Icon

**Source:** `/Users/matt/Documents/CrossLens-ScreenShots/app-icon.png`  
**Design:** CrossLens brand identity  
**Description:** Two offset rounded rectangular panes in teal gradient shades with a diagonal cream/white crossing line on a dark teal background, representing the "crossing lens" concept of comparing perspectives across sources.

**Specifications:**
- Original resolution: 1254x1254 pixels
- Format: PNG, 8-bit RGB
- Color palette: Dark teal background (#1A3540), teal/turquoise panes, cream crossing line

**Usage:**
- Android adaptive launcher icon (API 26+)
- Legacy launcher icons (all densities: mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi)
- Foreground layer: Full icon design with integrated background
- Background layer: Matching dark teal solid color (#1A3540)

**Generated Assets:**
- `app/src/main/res/drawable/ic_launcher_foreground.png` - 432x432px adaptive icon foreground
- `app/src/main/res/mipmap-mdpi/ic_launcher.png` - 48x48px legacy icon
- `app/src/main/res/mipmap-hdpi/ic_launcher.png` - 72x72px legacy icon
- `app/src/main/res/mipmap-xhdpi/ic_launcher.png` - 96x96px legacy icon
- `app/src/main/res/mipmap-xxhdpi/ic_launcher.png` - 144x144px legacy icon
- `app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` - 192x192px legacy icon
- Corresponding `ic_launcher_round.png` variants for each density

**Integration Date:** September 23, 2026  
**Version:** v0.0.6-beta

**Design Notes:**
The icon design aligns with CrossLens's editorial design system:
- Teal accent color consistent with app theme
- Offset panes motif represents multiple perspectives
- Diagonal crossing line symbolizes comparison and lens intersection
- Rounded rectangles match Material 3 design language
- Dark background provides good contrast on light and dark launcher themes
